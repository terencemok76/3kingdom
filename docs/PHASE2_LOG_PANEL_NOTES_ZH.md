# Phase 2 日誌面板實作備註

更新日期：2026-05-24

## 範圍
- 本文件補充 Phase 2 目前已落地的 HUD 日誌面板實作。
- 內容以目前程式行為為準，供後續 UI、log 規則與 playtest 對照。

## 標題與篩選
- 日誌面板標題顯示為：
  - 繁體中文：`日誌`
  - 英文：`Log`
- 日誌面板標題列提供兩顆篩選按鈕：
  - `本勢力`
  - `全部`
- 預設篩選模式為 `本勢力`。

## 顯示規則
- `本勢力`
  - 只顯示 `player-related log`
  - 也就是寫入 log 時 `isPlayerRelated = true` 的訊息
- `全部`
  - 顯示所有 log，不分勢力

## player-related log 約定
- 凡屬於玩家勢力直接操作、玩家城市月結算、玩家相關戰爭 / 外交 / 人事 / 內政結果，應盡量以 `isPlayerRelated = true` 寫入。
- 非玩家勢力的一般 AI 行動、他勢力之間的事件，可維持 `false`。
- 此旗標除了字色用途，也直接影響 `本勢力` 篩選是否可見。

## 資料流
- `v1 實作` 不再只把文字直接 append 到 `RichTextLabel`。
- 改為先保留 log entry，再依目前篩選模式重建顯示內容。
- 因此玩家切換 `本勢力 / 全部` 時，既有訊息會即時重新過濾。

## 初始日誌行為
- HUD 預設不再顯示 `Game initialized`。
- 初始化流程也不再自動加入 boot log。
- 目的：
  - 避免開局時先出現與玩家決策無關的預設訊息
  - 讓日誌更聚焦在實際回合內事件

## 其他 UI 備註
- 日誌面板右下角 resize handle 已從暫時字樣改為簡化符號顯示。
