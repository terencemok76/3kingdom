# 野戰地圖設計規則

本文件是新野戰地圖的共用設計基準。未來新增四張野戰時，先填完本文件的檢查項目，再建立 TileMap、Scenario Data 與部署。

## 1. 每張地圖必須有一個清楚的行軍問題

地圖的核心不是「看起來不同」，而是讓玩家在行軍、分兵或戰術上作出不同選擇。每張圖只能有一個主要壓力，再以一至兩個次要地形配合；不要同時堆入河流、沼澤、山口、森林與大量建築。

可選的主題包括：

- 開闊農田會戰：中央作物限制騎兵正面 Charge，兩翼草地保留包抄。
- 河谷搶橋：主橋快速但受威脅，淺灘或木橋是較慢的側翼選擇。
- 山口／丘陵防區：高地提供射程與視野價值，但仍必須有可供步兵突破的路線。
- 濕地伏擊：沼澤、淺水與堤路限制主力速度，鼓勵預判與伏擊。

## 2. 前線、縱深與撤退空間

- 前線接戰點可以是橋頭、渡口、谷口或道路入口；它的用途是延滯與決定初次接觸，不應直接決定勝負。
- 守軍後方必須保留撤退與重整空間，能從前線退回丘陵、建築或第二道防區。
- 攻方至少應有兩種可理解的推進方向：主路快但危險，側路較慢、較遠或較難支援。
- 不能以不可通行地形把戰場切成唯一走法；若有瓶頸，必須讓繞行、工人木橋或另一條地形路線成為有代價的選擇。

## 3. 堡壘（Fortress）規則

- 堡壘是縱深防線與反擊目標，不是前線裝飾或橋頭占點。
- 不得把堡壘貼近橋頭、渡口、谷口或第一個突破格；攻方跨越前線後仍須推進數回合才能爭奪。
- 堡壘應放在渡河／過隘後的丘陵、道路分岔、後方防區或側翼支點。
- 每座堡壘必須有戰術目的：控制主路、守側翼、保護撤退線或迫使攻方分兵。沒有目的的堡壘不要放。
- 堡壘附近應有守軍、可支援的射擊位置或反擊路線；未受守護的堡壘會變成免費勝利點。
- 攻方佔領全部堡壘後，仍須維持到守方回合結束；守方要有一回合反奪機會。

## 4. 地形與單位互動

- 丘陵必須能被守軍用作射程／防區優勢，不能只作背景，也不能讓堡壘取代其用途。
- 森林與作物應影響騎兵 Charge、Hide 或行軍，但不可覆蓋所有機動空間。
- 建築只提供可駐守與掩護；裝飾物件保持 visual-only，不得暗中改變移動、A* 或 AI。
- 河流以兩格深水時，石橋是主要通路；Worker 可在合法河段建木橋，需兩次施工，木橋不允許攻城器通過。
- 避免為單張地圖增加專用 runtime 規則；優先使用既有 Terrain、Bridge、Building、Fortress 與 Worker 規則。

## 5. 部署規則

- 初始部隊應是橋頭／谷口兵團或前後梯隊，不可整齊橫跨整張地圖。
- 守軍應在前線與縱深之間有明確職責：前線延滯、後方守堡、機動兵反擊。
- 攻方攻城器與補給車不得出生在 Building 格；野戰不部署 Ram 或 Ladder。
- Scenario Data 僅保存部署、天候、時段與 AI 提示；TileMap 保存地形與物件，runtime `BattleMapData` 負責規則、A* 與 AI。

## 6. 新地圖建立檢查表

- [ ] 每座堡壘均符合縱深規則，並寫明其控制目的與附近守軍。
- [ ] 檢查丘陵、森林、作物、河流與建築都有實際戰術作用。
- [ ] 確認物件裝飾不改變底層地形、移動、A* 或 AI。
- [ ] 檢查所有 UnitSpawnGrids 可通行；所有野戰的一般戰鬥單位與 Worker 都可直接出生於 Building 或 Fortress 格，以表現駐守／據點防禦。攻城器與補給車仍不出生於 Building 格，野戰沒有 Ram／Ladder。
- [ ] 以攻方「殲滅守軍」及「奪取所有堡壘」兩條路徑各做一次玩法檢查，確認其中一條不會過於容易。
- [ ] 驗證 RiverEffectLayer 只覆蓋該場景的深水格，並排除石橋與木橋施工格。

## 7. 已完成野戰的核心設計與特徵

### 鄴：開闊農田會戰

- 核心行軍問題：中央農田使騎兵無法以一次正面 Charge 解決戰線；攻方要決定強穿作物、沿兩翼草地包抄，或沿中央官道冒險集結。
- 守方優勢：雙格可通行乾溪低窪地 `(y=8..9)` 令中央接敵有速度代價；守軍出生時已駐守北側堡壘，可在作物戰線後建立第二道防線。
- 攻方優勢與選擇：西、東兩翼保留足夠草地，讓騎兵能繞過中央作物；但分兵包抄會拉長彼此支援距離。
- 堡壘目的：`(10,4)`、`(14,5)` 直接承載守軍出生格，控制中央官道兩翼；相鄰農莊建築 `(9,5)`、`(15,5)` 提供步兵掩護。攻方必須穿過農田／乾溪戰區後再分兵奪取兩堡，不能在前線接觸後立即靠占點取勝。
- 視覺辨識：作物邊緣與南側集結區使用農具、草垛與貨物裝飾；乾溪兩岸使用稀疏倒木、樹樁與灌木。這些均在獨立 visual-only layer，不改變草地包抄、乾溪通行、移動、A* 或 AI。
- 特徵：這是「正面受作物干擾、兩翼可包抄、後方要分兵奪堡」的純陸戰會戰；不加入河橋或大片丘陵，以維持與其他野戰的差異。

### 洛陽：河谷渡口與盆地會戰

- 核心行軍問題：攻方要穿過洛水河谷與濕地／岸地，才能接觸北側山麓防線；河谷是戰場中央的地形分界，而不是純視覺河流。
- 守方優勢：北側邙山山脊與山腳森林限制側翼，渡口北岸的聚落建築可成為步兵掩護點。
- 攻方優勢與選擇：南岸農地與開闊道路可集結主力；可選擇快速沿渡口官道集中突破，或利用山腳、農地支線分散守軍。
- 特徵：這是「地形層次多、但不以堡壘勝利為主」的河谷戰；重點是渡口、濕地、森林與建築如何改變接敵方式。

### 漢中：渡河後的縱深突破

- 核心行軍問題：先穿越雙格漢水，再在北岸防區中選擇主橋正攻、淺灘側進，或以 Worker 架木橋創造新線。
- 守方優勢：中央雙格石橋形成最快但最受火力控制的入口；北側秦嶺山前與守軍出生點保護後方防線。
- 攻方優勢與選擇：西側淺灘能避開正面橋頭，但移動較慢；木橋是額外的施工投資，不能讓攻城器通過。
- 堡壘目的：`(9,5)`、`(16,5)` 位於北岸山前縱深，分別由 `(10,6)`、`(14,6)` 守軍掩護。攻方跨河後仍須深入，不能把渡河或踏上橋頭當成直接勝利。
- 特徵：這是「渡河只是開始」的突破戰，考驗攻方何時分兵、何時保留兵力反奪堡壘。

### 晉陽：狹河谷搶橋與橋北防線

- 核心行軍問題：雙格汾河和唯一雙格石橋壓縮主力行軍，中央橋頭是最快、也最容易遭集中防守的通路。
- 守方優勢：南北兩岸的山體與可通行丘陵把戰線收進河谷；橋北出口兩側建築 `(10,8)`、`(12,8)` 與主堡壘 `(11,8)` 組成第二道步兵防線。
- 攻方優勢與選擇：可集中兵力強搶主橋，或由西側淺灘與 Worker 木橋尋找較慢的突破；通過河流後仍須面對橋北的掩護與反擊。
- 堡壘目的：主堡壘 `(11,8)` 控制橋北主路；側翼堡壘 `(15,6)` 防止攻方只沿主路推進後轉向包圍。
- 特徵：這是「窄正面、高支援密度」的河谷戰；勝負取決於渡河節奏與突破橋北防線的能力。

### 襄陽：丘陵火力防區與多點奪堡

- 核心行軍問題：雙格漢水與石橋形成正面接戰，但北岸大面積可通行丘陵才是守方真正的防禦地帶。
- 守方優勢：弓弩與步兵可利用丘陵建立互相支援的射程防區；最北山脊封住背景與側翼，不把丘陵變成無意義的死角。
- 攻方優勢與選擇：可在橋頭集中突破，也可在跨河後向西、北、東分兵；Worker 木橋提供額外但需施工的跨河選擇。
- 堡壘目的：西側丘陵 `(4,4)`、東側丘陵 `(19,4)`、北側預備線 `(10,5)`、東側防區 `(14,8)` 構成分散的縱深目標。攻方若只硬推橋頭，仍可能被丘陵防區反擊；若為全奪堡壘分兵，又會承受側翼風險。
- 特徵：這是「佔高地、拆解防區、再奪多點堡壘」的戰場，而不是兩個前線占點的兵力比拼。

### 下邳：水網堤路與縱深支援

- 核心行軍問題：兩條深水水道將戰場切分為陸塊；兩座雙格橋梁是最快的集中路徑，但必須在橋頭承擔被截斷的風險。攻方也可從西南 `(6..9,21..22)` 的寬淺水側路繞行，代價是較高移動消耗與較慢的支援速度。
- 守方優勢：北側水網後的穀倉聚落 `(13,8)`、`(15,8)` 可供步兵駐守，並能向兩條堤路提供支援；守方可延滯橋頭後，撤回水網後的縱深防區。
- 攻方優勢與選擇：可沿橋梁快速集中主力，也可讓側翼穿越淺水以牽制守軍。兩種走法的會合點不同，因此需要預先決定哪一支部隊保護補給與主路。
- 堡壘目的：`(16,3)` 控制北側堤路與西向回防，`(20,6)` 保護東側出口與守軍撤退線；兩者均位於過水後的縱深，不能由第一個橋頭接戰直接奪取。
- 視覺辨識：深水格以船筏、木樁與河岸物件描出水勢，聚落與堤路使用農具、草垛及稀疏林緣物件辨識。全部位於 visual-only layer，保留底層深水、淺水、橋梁與堤路的移動、A* 及 AI 規則。
- 特徵：這是「搶快橋、走慢渡、過水後再拆縱深」的水網戰，不加入城牆、大型山地或江陵式大片沼澤。

### 建業：石頭城、鍾山與長江防線

- 核心行軍問題：西側長江是不可跨越邊界，東北至東側的鍾山山體則形成連續屏障；兩團較密森林與階梯狀小丘壓住山麓路線，攻方只能在中央官道快速推進，或經較慢、受森林丘陵干擾的側翼迂迴。
- 守方優勢：長江岸的石頭城堡壘 `(4,5)` 控制沿江支路；鍾山驛站堡壘 `(16,7)` 位於第一線接戰後方，兩者讓守軍能依序延滯、撤退與反擊。
- 攻方優勢與選擇：官道讓主力和補給維持支援，但容易遭集中阻截；山麓側翼較慢，卻能繞過驛站正面並迫使守軍分兵。沿江低地 `(2..4,10..17)` 的濕地與泥地不提供渡河，只增加靠江行軍成本。
- 堡壘目的：石頭城 `(4,5)` 由江岸建築 `(3,6)`、`(5,6)` 支援，守住沿江支路；鍾山驛站 `(16,7)` 與聚落 `(13,8)`、`(15,8)` 守住中央與山麓的交界。攻方必須先突破平原接戰區，再選擇奪取兩個縱深支點或殲滅守軍。
- 視覺辨識：長江深水以不均勻分段的新船 `(0,2)`、礁石 `(1,2)`、船筏與繫船木樁描出航道及石頭城岩岸；石頭城周邊、濕地岸線與鍾山山腳各加低矮林緣物件。南側農莊以農具、草垛標出集結平原，濕地蘆葦與兩團較密山麓森林、小丘階梯共同勾勒水岸及鍾山界線。裝飾均位於 visual-only layer，不產生橋梁、淺灘或額外移動規則。
- 特徵：這是「長江封邊、石頭城控江路、鍾山壓山麓、守方逐段後撤」的江東野戰，保持與下邳水網渡河戰及晉陽搶橋戰的差異。

### 江陵：雙堤路與蘆葦沼澤伏擊

- 核心行軍問題：兩條縱向堤路是穿越江漢濕地最快的路徑，但兩條橫向淺水渠都會減速並暴露推進部隊；離開堤路進入泥地可繞行，卻會失去速度與支援。
- 守方優勢：西、東堤路北端的濕地寨堡 `(5,3)`、`(15,3)` 位於兩條淺水渠與中央泥沼之後，守軍可直接駐守堡壘及相鄰建築 `(6,3)`、`(14,3)`，形成真正的後方防線與反擊出發點。
- 攻方優勢與選擇：可集中衝過南側淺水渠後沿堤路北推，也可進入泥地與蘆葦邊緣迂迴；後者較慢，卻能讓兩座寨堡失去彼此的支援。
- 堡壘目的：`(5,3)` 守西側短堤北端與西部泥沼出口，`(15,3)` 守東側長堤北端與東部泥沼出口；兩者遠離中央接戰區，攻方必須跨越兩道水渠並穿過濕地縱深才能爭奪。
- 視覺辨識：兩條淺水渠使用不均勻分布的木樁、小舟與水面物件，但不繪成深水主河；兩座寨堡後方各有一座堤上聚落，三片泥沼及其邊緣加密蘆葦感林緣、竹叢、倒木與樹樁，南側高地農莊才使用農具與草垛。這些物件均為 visual-only，不改變堤路、淺水、泥地、移動、A* 或 AI。
- 特徵：這是「走堤路快但暴露、入濕地慢但可伏擊、跨水後再拆雙寨」的江漢濕地戰，不加入深水主河、石橋或大型山地。
