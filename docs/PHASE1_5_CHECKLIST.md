# Phase 1.5 Done / Partial / Missing Checklist

- 基準日期：`2026-05-02`
- 依據：目前 codebase、`PHASE1_DESIGN_ZH.md`、`MILESTONES.md`
- 用途：快速追蹤 Phase 1.5 已完成、部分完成、尚未完成項目

## Done

### 內政 / 民事
- `內政` 已取代 Phase 1 的單一 `Develop` 流程。
- `Farm`、`Commercial`、`Defend`、`WaterControl(防災)`、`Construction` 已有基本指派與月底結算。
- 內政支援多月排程。
- 玩家可在 UI 中中止內政排程。
- 同一名武將同月不能重複接多個指令。
- `救濟` 需要武將，且同城每月只能一次，於月底結算。
- `訪察民情` 需要武將，且同城每月只能一次，於月底結算。
- `民事` 主選單可直接顯示「本月已執行」禁用提示。

### 道具 / 勢力庫存
- 已有 `武器`、`馬`、`書`、`寶物` 四類基本道具資料。
- 搜索 / 訪察民情找到的道具會進入勢力庫存。
- `人事 -> 賞賜` 的道具來源為勢力庫存。
- `人事 -> 索回道具` 會把武將持有道具收回勢力庫存。
- `查看` 已可檢視勢力道具庫存。
- 道具能力加成已接入武將 / 城市 / 戰鬥相關計算。

### 六兵種 / 馬匹資源
- 城市已持有六兵種數量，不再只靠單一 `Troops`。
- 城市已持有 `馬` 資源。
- `商人` 可買馬。
- `移動` 可轉移馬匹。
- `騎兵` 徵募受馬匹數量上限限制。
- `弩兵` 徵募需要 `弓坊`。
- `攻城兵` 徵募需要 `工坊`。
- 起始劇本已改成預設無 `弓坊`，且起始 `弩兵 / 攻城兵` 為 `0`。
- 每年 1 月城市馬匹會自然繁殖。

### UI / 互動基礎
- 大部分武將清單 UI 已改成 table 風格。
- 多個複雜表單已開始由 `Window` 取代 `AcceptDialog`。
- `攻擊` 視窗已改為 `Window`。
- `攻擊` 已支援先選出征武將，再逐武將設定兵種與兵數。
- `攻擊` 的 `武將配兵` 區已支援獨立捲動。

### 防災 / 災害
- `治水` 已正式改名為 `防災`。
- 城市已有 `防災` 數值。
- 月底已存在基礎災害事件。
- `防災` 越高，災害發生率與損失幅度越小。

## Partial

- 已有逐武將配兵 UI。
- 已有兵種配置彙總與基本驗證。

- 目前仍在持續做 UI/UX 收尾，視窗排版與可讀性尚未完全穩定。

### 內政系統完整度

### 人事 / 官職

### AI Phase 1.5
