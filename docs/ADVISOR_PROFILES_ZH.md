# 顧問人格（`advice_profile`）

## 目的

建言的戰況資料與行動結果仍以同一套遊戲規則計算；`advice_profile` 決定武將如何解讀那些資料，而非複製一份只換姓名的公式。它會改變該武將特別看重的代價、可接受的風險與說話方式。

## 資料格式

`data/person/officer_data.json` 可選填：

```json
"advice_profile": "long_view_planner"
```

目前可用值：

- `long_view_planner`：重視長期糧餉、城防、人事連鎖。
- `opportunistic_tactician`：在有破綻時把握時機，但保留退路。
- `pragmatic_steward`：優先府庫、兵糧及可持續的收益。
- `diplomatic_bridge`：優先人心、關係與後續協商空間。
- `decisive_commander`：把握兵勢與士氣窗口，但須保留守備。
- `cautious_analyst`：先驗證敵情與最壞結果，再決定是否行動。

沒有填寫時，系統以智力、政治、統率、魅力與野心作**固定且可重現**的推導；因此新增開發中武將不會得到隨機人格。忠誠不參與這個推導。

## 使用位置

所有既有「軍師建言／內政建言／人事建言／外交建言／間諜建言」最後呼叫的共用顧問對話框，都會顯示一則完整建言。`advice_profile` 在背後改變與議題相關的判斷取向，不會額外顯示另一段人格或能力旁白；例如俘虜招降只評論成功率、贈禮、關係、職位與入隊價值，不能插入無關的城防或長期糧餉。這一階段不會修改命令成功率、戰鬥計算或遊戲存檔結果。

從特定指令開啟顧問對話框後，本地武將、軍師與丞相按鈕都會保留同一個問題與目前設定，分別留下各自的建言。具有一般 `Strategist` 任命的武將也可使用「請軍師建言」，不要求必須擔任 `ChiefStrategist`。

## 史料作為核心人物的起點

這些 profile 是遊戲化的「決策鏡頭」，不是對史實人格的唯一判定。核心設定以《三國志》傳記與學術／史料整理作為起點，日後可由資料編輯調整：

- [中國哲學書電子化計劃：《三國志・魯肅傳》](https://ctext.org/text.pl?if=en&node=604206) 記錄魯肅的資財經營、結士與政治活動，適合作為 `diplomatic_bridge` 的出發點。
- [《三國志》賈詡傳英譯與原文](https://kongming.net/biographies/sanguozhi/Jia-Xu/LadyWu) 記錄其因勢轉換、謀略與取捨，適合作為 `cautious_analyst` 的出發點。
- 諸葛亮、司馬懿等人物將以《三國志》本傳為優先依據；`advice_profile` 僅表達本遊戲的可玩性取向，不以小說演義直接當成史實。
