# Phase 2 事件演出與軍事 UI 實作備註

更新日期：2026-05-25

## 範圍

- 本文件補充 Phase 2 目前已落地的：
  - 月事件演出流程
  - 地圖事件標記規則
  - 軍事選將 UI 互動與視覺表現
- 內容以目前程式行為為準，供後續設計、UI 微調與 playtest 對照。

## 1. 月事件演出

### 1.1 事件資料來源

- 月事件演出資料來自：
  - `data/events/events.json`
- 目前每個事件定義可包含：
  - `eventType`
  - `picture`
  - `sound`
  - `durationSeconds`
  - `mapMarkerColor`

### 1.2 演出內容

- 當月底經濟與月事件結算完成後：
  - 事件會進入 presentation queue
  - 依序顯示事件圖片
  - 播放對應事件音效
  - 顯示事件 caption
- 多個事件不會同時播放，而是逐個排隊顯示。

### 1.3 同類事件合併播放

- 同一個月份內，若多座城市發生相同 `eventType`：
  - 事件演出只播放一次
  - 不重複顯示相同事件圖片與音效
- caption 會列出所有受影響城市
  - 例如：
    - `北海、洛陽 發生 地震`
- 合併規則只影響事件演出 queue
- 地圖上的城市事件標記仍然逐城保留，不會因為合併播放而只剩一座城顯示

### 1.4 圖片與音效

- 事件圖片來源：
  - `assets/event/`
- 事件音效來源：
  - `assets/sfx/events/`
- 若圖片缺失：
  - 仍保留 log 與地圖事件標記
- 若音效缺失：
  - 不阻斷事件播放流程

### 1.5 事件播放期間的 UI 可見性

- `End Turn` 後進入事件演出期間，會暫時隱藏非必要 UI
- 目前會暫時隱藏的內容包含：
  - 一般指令 / 功能 overlay dialogs
  - `城市資訊` 面板
- 目前保留可見的內容包含：
  - `top bar`
  - `log`
- 事件 overlay 會主動提到更高層級，顯示在 `top bar / log` 之上
- 當整段事件演出全部結束後：
  - 原本已開啟的 dialogs 會恢復顯示
  - `城市資訊` 面板也會恢復
  - 恢復時應盡量保留原本的視窗狀態與內容

## 2. 地圖事件標記

### 2.1 掛標時機

- `v1 實作`：
  - 月底事件一完成結算，就立即為所有受影響城市掛上事件標記
  - 不再等待事件圖片播放到該城市時才出現

### 2.2 保留時間

- 事件標記會保留整個月
- 到下一次月事件結算前，標記不會自動消失
- 下一輪月事件開始整理時，先清除上一輪月事件標記

### 2.3 視覺表現

- 城市圈圈外側會顯示事件脈動外環
- 目前為雙層效果：
  - 外層 glow
  - 內層較實的 pulse ring
- 城市名稱旁會顯示事件 tag
  - 繁中格式：`【事件名】`
  - 英文格式：`[Event]`
- 事件 tag 目前已加入深色陰影，降低底圖干擾

### 2.4 顏色區分

- 各事件使用 `events.json` 中的 `mapMarkerColor`
- `v1 調整`：
  - `plague` 改為較明顯的紫色系
  - `earthquake` 改為較明顯的亮橙系
- 原因：
  - 舊版 `plague / earthquake` 顏色在地圖底圖上不夠跳出

### 2.5 同城多事件

- 目前規則下，同一城市同一月份不會同時出現多個月事件
- 因此地圖標記目前只需要表示單一主事件

## 3. 軍事選將 UI

### 3.1 適用視窗

- 本節適用於：
  - `Attack`
  - `Move`

### 3.2 選取互動

- officer list 採用多選概念
- 第一欄顯示：
  - 未選：`○`
  - 已選：`●`
- 點擊 officer row 可切換選取狀態
- 已選 officer 會被納入後續出征 / 移動流程

### 3.3 視覺狀態

- 已選 row 會套用柔和高亮
- 高亮設計目標：
  - 可清楚辨識已選狀態
  - 但不要過亮、過銳利
- `v1 調整`：
  - 已選列改為較低飽和的霧金棕
  - 第一欄 `●` 亮度同步收斂

### 3.4 攻擊視窗中的配兵區

- `Attack` 視窗下半部會依已選 officer 動態生成配兵列
- 每列目前包含：
  - officer 名稱
  - troop type dropdown
  - troop count spinbox
- 這些動態生成控制項應套用與 overlay 一致的 input theme
